# Site Musica

## Objetivo
Este é o site pessoal de música do Nicolas, feito principalmente para praticar e aprender. Faça as mudanças que ele pedir, seguindo as preferências que indicar.

## Como trabalhar
- Antes de editar, entenda a estrutura e os padrões existentes; preserve tudo que não foi pedido para mudar.
- Prefira a menor mudança que resolva o pedido. Evite dependências e refatorações sem necessidade.
- Se houver uma dúvida pequena, escolha uma solução coerente com o projeto. Pergunte apenas quando a resposta puder mudar materialmente o resultado.
- Ao concluir, resuma brevemente o que mudou e indique os arquivos relevantes.
- Não publique o site nem crie releases sem pedido explícito.

## Eficiência
- Mantenha respostas e alterações focadas para economizar tempo e tokens.
- Para validações e tarefas simples, use um modelo rápido/econômico, como Luna.
- Para alterações pequenas de código, o modelo rápido costuma bastar; para bugs difíceis, múltiplas partes ou decisões arquiteturais, prefira um modelo de programação mais capaz.
- Rode testes ou verificações quando forem pedidos ou necessários para confirmar uma alteração com risco de regressão.
